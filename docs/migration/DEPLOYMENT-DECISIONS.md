## 独立域名不等于隔离资源

需标注 DNS → CDN/WAF → Nginx location → 实例 → DB/日志库/Redis → 上游渠道。若 `client.tsyqapi.top` 转发同一生产实例，仍共享生产数据、额度、计费与负载，不能承诺不影响原管线。生产接入以小批量灰度、限流及必要资源隔离降低影响。

临时裸机不得连接生产数据库/挂载生产数据目录；使用独立实例、脱敏快照或独立测试数据，测试上游用 mock 或限额渠道。账户/认证响应不公用缓存，SSE 缓冲、WAF、超时和断线行为实测。本段是验收要求，不代表已完成部署。

## 发布版本陷阱

上述标签首先用于服务端，客户端当前 Cargo 版本为 `0.2.8`，是否采用相同标签待确认；两个仓库不强制锁步。

按 SemVer 2.0.0 §9–11，连字符后的 `cjq.1` 本身是 prerelease 标识，所以通用 SemVer 工具也会将 `1.0.0-cjq.1` 当作预发布。本项目业务仍按用户要求认定其为正式；不得擅改标签，也不能粗略以“含连字符”判 RC。流水线须显式匹配业务标签、设置 GitHub prerelease/latest、控制 Docker latest 并拒绝未知格式。参考：`https://semver.org/`。

如客户端采用这套版本，需要内部安装版本/单调构建号及更新比较映射。现有 mac 发布脚本拒绝线上带连字符版本，Windows 比较丢弃后缀，不能仅改版本号就发包，详见 M-005。
